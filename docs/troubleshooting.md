## gemini api 호출 (무료)
- 문재 : api rate limit 문제 발생
- 해결책 : llm api 10초간 간격으로 호출, 임베딩 api 10개문서씩 10초 간격으로 호출

## 파일명이 중요한 키워드이지만 문서 내용으로만 검색하는 문제
- 각 청크별 내용 앞에 "상위폴더명/파일명"을 삽입하여 임베딩하여 벡터스토어에 저장

## 항상 참조문서 기반으로 RAG를하여 답변하는 문제
- 질문에 대해 라우터 기능으로 일반답변과 RAG답변을 구분하여 분기 처리

## 항상 프로그램 기동시 벡터스토어 생성에 30초 이상 걸리는 문제
1. 벡터스토어 영구 저장/로딩: FAISS 인덱스를 디스크에 저장하고 재시작 시 로드
2. 파일 변경 감지: PDF 파일의 수정시간과 해시값을 추적하여 변경사항 자동 감지  
3. 증분 업데이트: 새로운/수정된 파일만 처리하여 벡터스토어를 효율적으로 업데이트
4. 삭제 파일 처리: 삭제된 파일의 벡터 데이터를 제거하기 위한 전체 재구성 기능
5. 메타데이터 관리: 파일별 처리 이력을 JSON으로 관리

## 모델 변경 및 설정
- config.yaml에서 모델 변경 및 각종 설정이 가능하도록함

## 여러 모듈 로깅
- 여러 모듈이 import되어 사용됨에 따라, 로그에 각 모듈의 식별자가 표시되록하여, 어느 모듈에서 출력된 로그인지 구분할 수 있도록 함

## llm이 현재 일시를 모르는 문제
- 프롬프트에 현재 시간을 삽입하여, 현재 일시랑 관계되는 질문에 답변할 수 있도록 함.

## 프롬프트 수정이 어려운 문제
- 프롬프트를 하드코딩에서 jinja2 템플레이트 파일로 분리하여 쉽게 관리할 수 있도록함
